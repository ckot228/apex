# Техническое SEO APEX DETAILING

Вердикт: базовая реализация готова, production gate не пройден. Реальный production origin не указан; live browser QA заблокирован.

| Маршрут | Решение | Реализация |
| --- | --- | --- |
| Главная, вложенный путь репозитория | index | Русский HTML, один H1, H2 разделов и H3 услуг, title, description, OG, favicon, alt и якорные ссылки |
| credits.html | noindex,follow | Самостоятельные title/description, ссылки источников и лицензий |
| Несуществующий путь | not found | Локальный server.mjs возвращает 404; GitHub Pages требует post-deploy проверки |

Сборка получает SITE_URL только из настройки владельца или configure-pages. При его наличии создаёт canonical, OG URL/image и sitemap.xml с одной главной страницей. Служебная страница в sitemap не входит. При неизвестном origin canonical/sitemap не подделываются. robots.txt подкаталога не создаётся: обход управляется файлом в корне домена, который может обслуживать другие репозитории.

LocalBusiness, Review и Offer не применены: студия, цены и контактные сведения демонстрационные. Метаданные не обещают реальные услуги или подтверждённые результаты. Meta keywords, фиктивный lastmod и обещания индексации отсутствуют.

Статическая проверка ссылок и сборка прошли. HTTPS, реальные HTTP-статусы, опубликованный head, sitemap, OG-картинка и production SEO verification ещё не проверялись. Публикация не выполнялась.
